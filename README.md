# 🪙 Quantum Entanglement vs. Classical Coins Simulator

A Python-based interactive simulation and statistical proof demonstrating the fundamental difference between **independent classical coin flips** and **quantum-entangled qubits** (specifically utilizing the Bell state $|\Phi^+\rangle = \frac{|00\rangle + |11\rangle}{\sqrt{2}}$).

---

## 🚀 Features

* **Interactive Terminal UI:** Step through simulation rounds at your own pace by pressing `[ENTER]`.
* **Statistical Proof (1,000 Trials):** Runs large-sample trials to highlight probability distributions.
* **Classical Independent Logic:** Simulates two separate, uncorrelated coins split evenly across all 4 possible binary outcomes (`00`, `01`, `10`, `11`).
* **Quantum Correlation Logic:** Simulates a maximally entangled Bell state where mixed states (`01` and `10`) are strictly `0%`, proving absolute correlation (`00` and `11`)[cite: 37].

---

## 🛠️ Requirements

* Python 3.x installed on your system. 
* No external libraries required (uses Python's built-in `random` module).
